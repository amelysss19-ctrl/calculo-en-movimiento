¿CÓMO UTILIZAR CÁLCULO EN MOVIMIENTO? ＋

Ingresar una función

Escribe una expresión de x (por ejemplo, x^2 + 3x) y pulsa «Aplicar función» o Enter. Desde «Símbolos», elige cómo ingresar log: con una base o sin base (base 10). ln representa el logaritmo natural.

Cámara y gestos

Pulsa «Activar cámara» y concede permiso. Muestra la mano derecha: 1 dedo evalúa el punto x; 2 muestra la tangente; 3 muestra las derivadas; 4 analiza los puntos críticos; 5 activa el reto aplicado.

Zoom y navegación

Usa «+» y «−» para acercar o alejar, «↻» para restablecer y arrastra la gráfica para desplazarla.

Uso sin cámara

Selecciona «Manual» para evaluar puntos, mostrar la tangente y derivadas, calcular puntos críticos o activar el reto aplicado. El botón «Pausar» suspende las acciones manuales hasta reanudar.
